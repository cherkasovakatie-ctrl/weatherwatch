<div>
	<p><strong>PSL is creating a set of MJO timeseries that quantify current and historic MJO activity.</strong> Links
		and descriptions are below as well as links to some other MJO timeseries created at other institutions. A <a
			href="/mjo/mjoindex/format.html">description of the timeseries format</a> is available.</p>
</div>
<div class="alert alert-warning" style="text-align: left;">
	<strong>NOTE</strong>: ROMI is now provided in near real-time. The OMI has changed to use NOAA CPC blended OLR and has been updated through <strong>June 24 2026</strong>. These PC amplitudes will differ slightly from the previous version since the sample used for the 20-96 day filter differs in addition to the OLR data ingested, resulting in slightly different values for the filtered OLR used to calculate OMI. In some cases this may also result in a phase difference (by one phase) from the previous versions. The correlations between the old and new OMI PC1, PC2, and their amplitudes exceed 0.99 at zero lag. The EOFs used are still from 1979-2012 (see below). The previous (1979-2021) version of OMI can be obtained <a href="/mjo/mjoindex/omi.1x.orig.txt" class="under">here</a>. This index will <strong>not be updated</strong> in the future. If recent values are needed, please use the OMI based on the CPC blended OLR.
